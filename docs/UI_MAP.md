# خريطة الواجهة (UI_MAP.md)

## 1. قائمة الشاشات والـ Routes
| الشاشة | المسار (Route) | الصلاحية المطلوبة |
|---|---|---|
| تسجيل الدخول | `/login` | `public` |
| لوحة التحكم (Dashboard) | `/` | `reports.view` |
| العملاء | `/customers` | `customers.view` |
| تفاصيل العميل | `/customers/:id` | `customers.view` |
| التقارير | `/reports` | `reports.view` |
| التنبيهات والصيانات | `/alerts` | `customers.view` + `visits.view` |
| المستخدمون والأدوار | `/users` | `users.view` |
| الإعدادات | `/settings` | `settings.update` |
| سجل العمليات (Audit) | `/audit` | `audit.view` |
