# دروس وأخطاء يجب تفاديها (LEARNINGS)

هذا الملف يحتفظ بالأخطاء التي واجهناها مسبقاً لمنع تكرارها في المراحل القادمة:

## 1. التعامل مع مكتبات C++ (Node-Gyp)
- **المشكلة:** فشل تثبيت مكاتب مثل `better-sqlite3` و `argon2` بسبب اعتمادها على `node-gyp` ومترجم C++ (Visual Studio) وهو غير متوفر في بيئة العميل.
- **الحل الدائم:** الاعتماد دائماً على البدائل التي تعمل بـ Pure JavaScript أو WebAssembly.
  - بديل SQLite: استخدام `@libsql/client`.
  - بديل التشفير: استخدام `bcryptjs` بدلاً من `argon2` أو `bcrypt`.

## 2. تشغيل بيئة العمل (Monorepo)
- **المشكلة:** استخدام أمر `npm run dev --workspaces` يقوم بتشغيل الـ Backend فقط وينتظر انتهاءه (بشكل تسلسلي) مما يمنع الواجهة الأمامية من العمل.
- **الحل الدائم:** تم تثبيت حزمة `concurrently` في الجذر (Root) وتعديل الأمر ليكون:
  `"dev": "concurrently \"npm run dev -w server\" \"npm run dev -w frontend\""`
  يجب التأكد مستقبلاً من تشغيل الخوادم بشكل متوازي (Parallel).

## 3. إعدادات Tailwind CSS
- **المشكلة:** عند استخدام متغيرات CSS (مثل `--border`, `--background`) عبر طبقة `@layer base` وإضافة فئات تعتمد عليها مثل `border-border`، تعطل مترجم Vite بسبب عدم وجود تعريف لهذه المتغيرات في `tailwind.config.js`.
- **الحل الدائم:** عند إضافة أي متغيرات في `index.css` (مثل نظام ألوان Shadcn UI)، يجب دائماً وبشكل متزامن تعريفها في قسم `extend.colors` داخل ملف `tailwind.config.js`.

## 4. نظام التشغيل
- بيئة العميل هي Windows و PowerShell، مما يعني أن علامة `&&` قد تفشل في بعض إصدارات PowerShell. 
- **الحل الدائم:** تشغيل الأوامر المعقدة عبر `cmd.exe /c "..."`.
