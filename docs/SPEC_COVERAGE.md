# تغطية المواصفات (SPEC_COVERAGE.md)

تقوم هذه الوثيقة بربط الأقسام الـ 12 المذكورة في `MASTER_SPEC.md` بملفات التصميم لضمان عدم ترك أي متطلب.

| القسم في `MASTER_SPEC.md` | تمت التغطية في | ملاحظات التعطية |
|---|---|---|
| **أولاً: البنية التقنية** | `ARCHITECTURE.md`, `SECURITY.md` | فصل الواجهة والمنطق، حماية العمليات، دعم المزامنة (SSE). |
| **ثانيًا: المستخدمون والصلاحيات** | `RBAC_MATRIX.md`, `DATABASE.md` | جدول `users`، سجل `audit_logs`، نظام `Deny-by-default`. |
| **ثالثًا: العملاء** | `DATABASE.md`, `UI_MAP.md` | جدول `customers` يحتوي على الهواتف والعنوان ومدة الصيانة. |
| **رابعًا: ملف العميل** | `UI_MAP.md`, `API.md` | صفحة `Profile` مستقلة، تعرض تواريخ آخر/أقرب صيانة. |
| **خامسًا: سجل الصيانة** | `DATABASE.md`, `API.md` | جدول `visits` يخزن الشموع السبع لكل زيارة منفصلة بشكل مستقل. |
| **سادسًا: الصيانة والتنبيهات** | `KPI_DICTIONARY.md`, `ARCHITECTURE.md` | تعريف حالات المواعيد (اليوم، متأخرة، قادمة) وحسابها التلقائي. |
| **سابعًا: البحث** | `DATABASE.md` | توفير Index لـ `pg_trgm` للبحث المتقدم في العناوين والأسماء. |
| **ثامنًا: Dashboard** | `UI_MAP.md`, `KPI_DICTIONARY.md` | خريطة الواجهة للرئيسية مع توضيح جميع المؤشرات الـ 10 المطلوبة. |
| **تاسعًا: التقارير** | `API.md` | مسار `/api/v1/export/*` للتصدير، ومسارات جلب إحصائيات الموظفين والشمع. |
| **عاشرًا: التصميم** | `DECISIONS.md`, `UI_MAP.md` | قرار (A-02) لاستخدام خط عربي بديل عن Calibri للتوافق مع Self-host، دعم الـ RTL والـ Dark mode. |
| **الحادي عشر: الأمان** | `SECURITY.md` | منع الهجمات، عدم تخزين مفاتيح سرية، حماية كلمات المرور (Argon2id). |
| **الثاني عشر: قابلية التطوير** | `DATABASE.md`, `ARCHITECTURE.md` | بنية Modular تسمح بإضافة `inventory` و `invoices` لاحقاً دون كسر النظام الحالي. |
