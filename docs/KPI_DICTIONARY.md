# قاموس مؤشرات الأداء (KPI_DICTIONARY.md)

توقيت حساب جميع المؤشرات هو توقيت القاهرة `Africa/Cairo`، لتجنب تضارب التواريخ (L-11).

## 1. محددات الزمن
- **اليوم (Today):** تاريخ اليوم الحالي بتوقيت القاهرة `YYYY-MM-DD`.
- **هذا الأسبوع (This Week):** من يوم السبت الماضي (أو بداية الأسبوع المحددة) إلى اليوم.
- **هذا الشهر (This Month):** من اليوم الأول في الشهر الحالي إلى اليوم الأخير.

## 2. قائمة المؤشرات (KPIs)
| المؤشر | التعريف الرياضي / استعلام SQL الأساسي |
|---|---|
| **إجمالي العملاء** | عدد السجلات في `customers` حيث `is_deleted = false`. |
| **صيانات اليوم** | عدد السجلات في `visits` حيث `visit_date = Today`. (الصيانات التي تمت اليوم). |
| **الصيانات المتأخرة** | عدد العملاء الذين لديهم `next_maintenance_date < Today`. |
| **الصيانات القادمة** | عدد العملاء الذين لديهم `next_maintenance_date >= Today`. (يُستثنى منها المتأخرة). |
| **إجمالي صيانات الشهر** | عدد السجلات في `visits` حيث `visit_date` يقع ضمن الشهر الحالي. |
| **العملاء حسب المحافظة** | تجميع (GROUP BY) لـ `customers` حسب `governorate` وعَدّ السجلات. |
| **استهلاك الشمع (اليوم/الشهر)** | عَدّ (COUNT) الحقول `item_1`, `item_2`... عندما تكون `true` في جدول `visits` ضمن فترة زمنية محددة. |
| **أداء الموظفين** | تجميع (GROUP BY) لـ `visits` حسب `employee_id` لحساب عدد الصيانات التي أنجزها كل فني. |

## 3. تعريف حالات الصيانة للعميل (Due State)
كما ذُكر في `DATABASE.md`، تعتمد جميع قوائم التنبيهات على المتغير `next_maintenance_date`:
1. **قادمة:** إذا كان الموعد القادم أكبر من تاريخ اليوم.
2. **اليوم:** إذا كان الموعد القادم يطابق تاريخ اليوم.
3. **متأخرة:** إذا كان الموعد القادم أقدم من تاريخ اليوم ولم تتم الصيانة.
